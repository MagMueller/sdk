A **browser profile** is saved login/cookie state — the "stay logged in" of a real browser. It's a standalone, project-owned resource: you create it once, then reference it by id whenever you want a browser or an agent run to start already logged in.

## Create a profile

<CodeGroup>
```python Python
from browser_use import BrowserUse

client = BrowserUse()
profile = client.browser_profiles.create(name="my-gmail")
print(profile.id)   # bp_...
```
```bash curl
curl -X POST https://api.browser-use.com/api/v1/browser-profiles \
  -H "X-Browser-Use-API-Key: $BROWSER_USE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "my-gmail"}'
```
</CodeGroup>

The agent (or you, over CDP) logs in once inside a browser started with this profile; the session is saved back to the profile for next time.

## Use a profile

Pass `browser_profile_id` into a run or a standalone browser — same field either way.

<CodeGroup>
```python Python
# in an agent run
run = client.agents.browser_use.run(
    task="Check my inbox and summarize unread emails",
    browser_profile_id=profile.id,
)

# or a standalone browser
browser = client.browsers.create(browser_profile_id=profile.id)
```
```bash curl
curl -X POST https://api.browser-use.com/api/v1/agents/browser-use/runs \
  -H "X-Browser-Use-API-Key: $BROWSER_USE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"task": "Check my inbox", "browser_profile_id": "bp_123"}'
```
</CodeGroup>

## Manage

<CodeGroup>
```python Python
client.browser_profiles.list()
client.browser_profiles.get("bp_123")
client.browser_profiles.update("bp_123", name="renamed")   # edit fields
client.browser_profiles.delete("bp_123")
```
```bash curl
# rename — PATCH edits fields (not lifecycle)
curl -X PATCH https://api.browser-use.com/api/v1/browser-profiles/bp_123 \
  -H "X-Browser-Use-API-Key: $BROWSER_USE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "renamed"}'
```
</CodeGroup>

<Note>
A profile is a creation input, passed by id — never nested under a browser. There is no `browsers/{id}/profile`.
</Note>
